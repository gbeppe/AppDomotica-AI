## Lezioni tecniche

| Tema | Lezione |
|---|---|
| Node-RED, pacchetti della palette | Toglierli **solo tramite Node-RED** (palette o Admin API `DELETE /nodes/<modulo>`), che rifiuta i moduli con nodi in uso, mai con `npm uninstall`: con un tipo mancante Node-RED non avvia **nessun** flow («Waiting for missing types»). Per sapere cosa è usato chiedere a Node-RED (`GET /nodes` e `GET /flows`), non cercare i nomi nei file dei pacchetti (26/10: `moment` sfuggito, flow fermi 3 minuti). |
| Immagini dei Raspberry | Un'immagine con gli stessi PARTUUID della SD non va aperta con `losetup -P` sul Raspberry acceso: udev sposta i link `/dev/disk/by-partuuid` sul disco virtuale e, alla chiusura, systemd smonta le partizioni montate per PARTUUID (`/boot` del `.20`, 26/10). Aprire ogni partizione con offset e dimensione. Prove pesanti (rsync dell'intero sistema) sui Raspberry di casa portano il `.20` a non rispondere: due volte il 25–26/10; un controllo della memoria in SSH non basta, perché anche SSH si blocca. |
| Alexa (hub Hue emulato) | Gli Echo recenti chiamano il ponte Hue **solo sulla porta 80**, qualunque porta annunci `amazon-echo-hub`: senza la porta 80 i dispositivi si scoprono a volte e poi «non rispondono», e ogni riscoperta crea doppioni. Un reindirizzamento iptables si perde quando le regole del firewall vengono riscritte: meglio un proxy di Apache, già sulla 80, per `/api` e `/description.xml` (ALEXA-HUE.1). - Vive solo in Node-RED `.20`, scheda "AI Climate - Predictive Reserve"; la catena è: controller
  clima (`61992c88…`, uscita 6) → link call (timeout 2 s) → SHADOW Engine → Final SHADOW Decision →
  Arbitration Snapshot → Shared Arbitration Gate → Pre-start Result → "AI Climate NIGHT_DRY Commit"
